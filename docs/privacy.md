# private-sms-server 隐私政策

生效日期：2026-10-10

本政策适用于 hvsop 发布的 private-sms-server iPhone 客户端。开源项目与支持入口：https://github.com/hvsop/sms-forward-solutions 。客户端用于查看由用户授权的安卓设备转发到所选服务的短信，不读取 iPhone 系统短信。

## 数据如何处理

- **短信与关联信息**：安卓端在用户授权并开启转发后，将新 SMS 的发件人、正文、接收时间及 SIM 信息上传至用户选择的服务。iPhone 经 HTTPS 从同一服务读取。短信可能包含验证码或其他敏感内容。
- **账户与配对信息**：服务使用独立账户标识、读取令牌和设备配对凭据区分用户。iPhone 将服务地址及读取令牌保存在本机钥匙串，不通过本 App 同步到 iCloud。请勿向他人泄露令牌或配对码。
- **推送设备令牌和未读数**：开启通知后，iPhone 将 Apple 分配的推送设备令牌提交给所选服务，用于通知投递。Apple APNs 接收设备令牌、通用提醒和未读角标；本项目不将短信正文、号码、验证码或短信 ID 写入推送载荷。
- **网络信息**：托管服务及网络提供商可能处理 IP 地址、连接时间及安全日志，用于请求传输、限流、故障排查和防护。Cloudflare 托管的服务由 Cloudflare 处理 HTTPS 请求与存储。
- **可选 Apple 登录**：仅在发行版配置了支持该功能的服务时提供。该服务会验证 Apple 登录授权并保存用于关联账户的 Apple 用户标识；本 App 不申请 Apple 邮箱或姓名。Cloudflare 精简版使用读取令牌连接，不提供 Apple 自助开通。

应用不包含广告、广告标识符读取、跨应用追踪或第三方行为分析 SDK；不出售个人数据。数据处理仅用于短信同步、配对、通知、账户管理和保障服务运行。

## 服务运营者与加密边界

你可以连接自己部署或可信管理员提供的兼容服务。所选服务的运营者控制该服务的数据处理与保留规则；请在连接前向其确认隐私政策。开源代码公开不代表你已获得公共托管账户，也不代表所有第三方服务采用相同配置。

hvsop 管理的邀请制 Cloudflare 服务（smsfree.kuaapi.com）由项目维护者管理，短信存储在 Cloudflare。短信经 HTTPS 传输并在后端加密存储，但**不是端到端加密**：服务运营者及运行环境有能力解密短信。不要向不信任的服务提交短信或账户凭据。

## 本机保护与演示

已连接的收件箱使用 iOS 设备认证（Face ID、Touch ID 或设备密码）解锁。应用不获取或保存生物识别数据。短信正文只在解锁期间保留内存副本，进入后台后清理；App 切换器中显示遮罩。复制功能使用仅本机剪贴板并设置 90 秒过期；用户粘贴到其他应用后，副本由目标应用管理。

“先看看演示”仅使用内存中的虚构数据，不连接短信服务、不上传数据、不注册推送，不改变真实收件箱。

## 保留、删除和撤回授权

hvsop 邀请制 Cloudflare 服务默认保留短信 7 天，每账户最多 500 条；到期数据由服务清理。自行部署的 Go 服务默认保留 7 天、每账户最多 5,000 条；自建服务管理员可能修改配置或保留备份，应另行说明。

- iPhone 内可删除单条短信，或在设置中“清空全部短信”；清空会保留账户和配对。
- 在“设置 → 账户管理 → 注销账户”确认后，服务会删除当前账户及短信，使读取令牌、安卓配对和推送注册失效，并清除本机连接凭据。
- 安卓关闭转发后不再上传新短信；可撤销短信权限或解除配对。关闭转发不会自动删除已上传数据。
- 可在 iOS 系统设置中关闭通知。卸载 App 不等于注销服务器账户；请先在 App 中注销，或联系服务管理员处理。
- 删除服务端数据不能收回用户已经复制、截屏或下载到其他位置的副本。

## 联系与政策更新

使用问题与隐私请求可通过 [项目支持页面](https://github.com/hvsop/sms-forward-solutions/issues) 联系 hvsop。公开 Issue 中不要发送手机号、短信、验证码、令牌或其他个人资料；涉及账户的请求请使用管理员向你提供凭据时的私下联系渠道。安全问题请使用 [私密漏洞报告](https://github.com/hvsop/sms-forward-solutions/security/advisories/new)。第三方自建服务的数据请求须联系相应服务管理员。

政策更新会发布在本页并修改生效日期。若后续引入与上述用途不兼容的数据处理，将先更新告知与必要的授权流程。
