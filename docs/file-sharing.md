# Go 中保留的文件分享实验代码

文件分享开发已暂停，当前开源主线是短信。本仓库保留 `server/share.go`、`server/shareweb/` 和相关测试，避免把现有 Go 代码不完整地截断。它不是 Cloudflare 免费版功能，也未作为当前手机端交付范围。

独立分享账户可由 `-create-share-user` 创建，入口 `/share`；短信账户不能访问分享账户数据。浏览器 AES-GCM 加密分块文件，密钥放 URL fragment，服务端保存密文。页面供应者仍在信任边界内，不能抵御未来被篡改的网页代码。

目前上限：单文件 100 MiB、每账号 10 文件/500 MiB、全站 2 GiB/512 文件、完成文件 24 小时到期、未完成 1 小时。真实手机文件分享兼容性仍需独立测试，不宣称已正式支持。

`node scripts/tests/share-crypto.mjs` 验证虚构数据的加解密与篡改拒绝。线上 transfer 脚本仅可对自己授权的隔离测试账户运行，不要放真实个人文件或分享令牌到 Issue。
